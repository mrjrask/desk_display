{# Shared screen rotation editor: playlist groups, drag-and-drop screen order, frequency, speed, hide-after, alternates, extra seconds and alternate frequency. Used by the Screen Rotation Config page (/) and the Client Playlists page (/playlists); each page creates it with createRotationEditor(options) and owns loading and saving. #}
How the columns work
Drag ☰
Drag a screen to reorder it. Group screens into playlists, then move whole playlists with their Move buttons.
Freq
0 disables the base screen. All enabled screens play in cycle 1, subject to availability. 1 = every cycle; 2 = cycles 1, 3, 5; 3 = cycles 1, 4, 7.
+Sec
Extra seconds added to this screen's display time.
Alternate
A screen that sometimes plays in this screen's place.
Alt every
How often the alternate plays. Counts the base screen's scheduled appearances, including cycle 1. Blank means 1.
Hide after
When checked, the screen stops playing after this date and time.
Speed
When checked, overrides this screen's scroll speed.
