Add a display

A guided setup checks this server can be reached, creates the display's own credential and gives you one command to paste on the new Pi.

Run this on the display's Pi. It works once, for the next 30 minutes, and sets up the display with a fresh credential.

Copy this into .env.client on the display now (replace its DESK_DISPLAY_CLIENT_TOKEN line), then restart the display's client service. The credential is never shown again; if it is lost, rotate it.

Saved is the revision stored on the server, delivered is the one the server last sent to the client, and acknowledged is the one the client reported playing.
